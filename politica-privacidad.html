Política de Privacidad

Última actualización: septiembre de 2026

Responsable: Carolina Elizabeth Arroyo

Carolina Elizabeth Arroyo es responsable del tratamiento de los datos personales que se recopilan a través de este sitio web y de los medios de contacto asociados a la actividad de Mujer Expansiva.

2. ¿Qué datos personales se recopilan?

Dependiendo de la forma en la que contactes, solicites información o contrates un servicio, pueden recopilarse los siguientes datos:

  • Nombre y apellidos.
  • Dirección de correo electrónico.
  • Número de teléfono o WhatsApp.
  • Datos necesarios para gestionar una reserva.
  • Datos necesarios para gestionar una compra o contratación.
  • Información que la persona facilite voluntariamente al solicitar un servicio.

Se procurará recoger únicamente aquellos datos que sean adecuados, pertinentes y necesarios para la finalidad correspondiente.

No es necesario proporcionar información médica, diagnósticos, medicación ni otros datos relativos a la salud a través de los formularios de contacto o solicitud de servicios.

3. ¿Cómo se recopilan los datos?

Los datos personales pueden ser proporcionados directamente por la persona interesada a través de:

  • Formularios disponibles en el sitio web.
  • Formularios de Tally.
  • Herramientas de reserva como Calendly.
  • Correo electrónico.
  • WhatsApp.
  • Redes sociales.
  • Procesos de compra de productos o servicios.

También pueden intervenir plataformas externas utilizadas para gestionar pagos, reservas, formularios o la entrega de productos digitales.

4. Finalidades del tratamiento

Los datos personales podrán utilizarse para las siguientes finalidades:

  • Responder consultas y solicitudes de información.
  • Gestionar solicitudes de Sesiones de Claridad.
  • Contactar con la persona interesada.
  • Gestionar reservas y citas.
  • Prestar los servicios contratados.
  • Gestionar la relación con las clientas.
  • Gestionar pagos, compras y contrataciones.
  • Entregar productos digitales adquiridos.
  • Gestionar incidencias relacionadas con los servicios o productos.
  • Cumplir las obligaciones legales que correspondan.

Los datos no serán utilizados para finalidades incompatibles con aquellas para las que fueron recopilados.

5. Base jurídica del tratamiento

El tratamiento de los datos personales se realizará, según corresponda, sobre las siguientes bases jurídicas:

Consentimiento: cuando la persona haya prestado su consentimiento para una finalidad concreta y dicho consentimiento sea la base jurídica correspondiente.

Medidas precontractuales o ejecución de un contrato: cuando los datos sean necesarios para gestionar una solicitud, reserva, compra o prestación de un servicio.

Cumplimiento de obligaciones legales: cuando el tratamiento sea necesario para cumplir las obligaciones legales aplicables.

Interés legítimo: cuando resulte aplicable y siempre que se respeten los derechos y libertades de la persona interesada.

Cuando el tratamiento requiera consentimiento, este será solicitado mediante una acción afirmativa, específica e informada.

El consentimiento podrá retirarse en cualquier momento.

6. Uso de proveedores y plataformas externas

Para desarrollar su actividad, Mujer Expansiva utiliza diferentes proveedores tecnológicos.

Actualmente pueden intervenir, entre otros:

  • Tally, para la creación y gestión de formularios.
  • Calendly, para la gestión de reservas.
  • Hotmart, para la gestión y entrega de determinados productos o contenidos digitales.
  • PayPal, para la gestión de pagos.
  • Servicios de correo electrónico, alojamiento web y otras herramientas necesarias para el funcionamiento de la actividad.

Estas plataformas pueden tratar determinados datos personales de acuerdo con sus propias condiciones y políticas de privacidad.

Cuando corresponda, se establecerán las garantías necesarias para que el tratamiento de los datos se realice conforme a la normativa aplicable.

7. Datos facilitados en el formulario de Sesión de Claridad

En el formulario destinado a solicitar una Sesión de Claridad se pueden solicitar datos como nombre, correo electrónico, teléfono y determinada información relacionada con el motivo por el que la persona solicita la sesión.

La finalidad de esta información es conocer de forma general el motivo de la solicitud, poder valorar si el servicio ofrecido resulta adecuado y, cuando corresponda, contactar con la persona para gestionar la sesión.

Se solicita a las personas interesadas que no incluyan en el formulario diagnósticos médicos o psicológicos, información sobre medicación, historial clínico ni otros datos especialmente sensibles que no sean necesarios para gestionar la solicitud.

La información proporcionada será tratada de forma confidencial y únicamente para las finalidades indicadas.

Los datos relativos a la salud constituyen una categoría especial de datos personales y cuentan con una protección reforzada conforme al RGPD.

8. Conservación de los datos

Los datos personales se conservarán durante el tiempo necesario para cumplir las finalidades para las que fueron recopilados.

Cuando exista una relación contractual, podrán conservarse durante el tiempo necesario para gestionar dicha relación y posteriormente durante los plazos exigidos por las obligaciones legales aplicables.

Cuando los datos se hayan proporcionado para solicitar información y no llegue a establecerse una relación contractual, se conservarán durante el tiempo necesario para atender la solicitud y posteriormente durante el plazo necesario para cumplir las obligaciones legales o determinar posibles responsabilidades.

Los datos tratados sobre la base del consentimiento se conservarán mientras este no sea retirado, salvo que exista otra base jurídica que permita su conservación.

9. Confidencialidad y seguridad

Carolina Elizabeth Arroyo se compromete a tratar los datos personales de forma confidencial y a adoptar las medidas técnicas y organizativas adecuadas para protegerlos frente a pérdida, destrucción, alteración, acceso no autorizado o tratamiento indebido.

Las medidas de seguridad se determinarán teniendo en cuenta la naturaleza de los datos tratados, el contexto del tratamiento y los riesgos existentes.

10. Derechos de las personas interesadas

La persona interesada puede ejercer los siguientes derechos:

  • Derecho de acceso.
  • Derecho de rectificación.
  • Derecho de supresión.
  • Derecho de oposición.
  • Derecho a la limitación del tratamiento.
  • Derecho a la portabilidad de los datos cuando resulte aplicable.
  • Derecho a retirar el consentimiento cuando el tratamiento se base en él.

Para ejercer estos derechos puedes enviar una solicitud a: tarotcarolinaariel@gmail.com

La solicitud deberá indicar qué derecho se desea ejercer y aportar la información necesaria para poder identificar a la persona solicitante.

El ejercicio de estos derechos es, con carácter general, gratuito.

Asimismo, si consideras que el tratamiento de tus datos personales no se ajusta a la normativa aplicable, puedes presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD).

11. Comunicaciones comerciales

Los datos de contacto no serán utilizados para enviar comunicaciones comerciales para finalidades distintas de aquellas para las que fueron proporcionados, salvo que exista una base jurídica que lo permita o el correspondiente consentimiento cuando sea necesario.

Cuando se solicite consentimiento para recibir comunicaciones comerciales, este será independiente de la aceptación de la presente Política de Privacidad.

La persona interesada podrá retirar su consentimiento para recibir comunicaciones comerciales en cualquier momento.

12. Enlaces a terceros

Este sitio web puede contener enlaces hacia páginas o servicios de terceros.

Mujer Expansiva no es responsable de las prácticas de privacidad, contenidos o condiciones de dichos sitios web externos.

Se recomienda consultar las políticas de privacidad correspondientes antes de proporcionar datos personales a terceros.

13. Menores de edad

Los servicios y contenidos ofrecidos por Mujer Expansiva están dirigidos a personas mayores de edad.

No se pretende recopilar deliberadamente datos personales de menores de edad.

Si se detectara que se han recopilado datos de una persona menor de edad sin la autorización correspondiente, se adoptarán las medidas necesarias para proceder a su eliminación cuando corresponda.

14. Actualizaciones de esta Política de Privacidad

Esta Política de Privacidad podrá modificarse cuando resulte necesario para adaptarla a cambios legislativos, técnicos, organizativos o relacionados con la actividad de Mujer Expansiva.

La versión vigente será la publicada en este sitio web.
